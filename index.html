One-Button Desk: Stream Deck Automation System

A 15-key Stream Deck turned into the front panel for my daily work. Every repeat task, from logging a quality result in Excel to filing an email or starting an AI prompt, is one labeled button. The goal: everything has a button, and nothing depends on remembering a shortcut.

Portfolio version: layouts and labels are generic. Tap any key to see what it triggers.

15 keys, 3 x 5

Top row switches pages on every page, so you can never get lost. Keys marked "planned" are designed but not built yet. Dark keys are open slots.

Design rules

Everything has a buttonIf a task repeats more than a few times a week, it gets a key. No digging through menus.
Nothing requires memoryEvery key is labeled, so no one has to memorize a keyboard shortcut. The deck shows what is possible.
Same top row everywherePage navigation never moves. The Home page is identical in every profile, so muscle memory carries over.
Color means statusOne color system across Excel, email and tasks. Green always means pass, amber always means needs a look.
Most-used stays on topThe most common action sits on the main page; rarer variants live one level down.
Every action is loggedExcel macros record what they did on a hidden log sheet, so any change can be traced and undone.

What's behind the buttons

Excel VBA frameworkEvery macro follows the same four steps: validate the selection, act, log to a hidden sheet, give feedback. One pattern makes new macros fast to build and safe to run.
AutoHotkey v2System-wide text expansion for 10 AI prompt templates and a save-and-close shortcut that work in any app.
Power AutomateButton-triggered cloud flows, built on a lookup table instead of nested switch logic, so adding a route means adding a row.
Screen capture presetsSix capture types (region, full screen, scrolling, video, text grab, panorama) for documentation and quality reports.
Icon generatorA Python and Pillow script that draws every key from one spec: 160 icons in 15 packs, rendered at 4x and downscaled for crisp edges.
AI that can press buttonsConnected Claude to the deck through Elgato's MCP server. Keys marked AI-ready can be triggered by asking Claude in plain language.

Hotkey conflict audit

Before assigning shortcuts, I audited all 26 Ctrl+Shift+letter combinations against the apps I use, and rated each one for conflict risk before rollout. The two high-risk findings:

ShortcutAlready used byRiskDecision
Ctrl+Shift+RReply All in the email clientHighFlagged before rollout: pressing it in the wrong window sends a reply to everyone.
Ctrl+Shift+LFilter toggle in ExcelHighFlagged before rollout: would silently toggle filters while working in Excel.
